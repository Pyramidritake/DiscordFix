Сначала включите безопасный DNS (Secure DNS).\n    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-поставщика, отличного от "Поставщик по умолчанию".\n    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.\n    * Windows 11 позволяет включить Secure DNS в настройках самой ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется.\n    * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.\n\n2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Pyramidritake/zapret-discord-youtube/releases/latest).\n\n3. Откройте свойства архива и отметьте "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять.\n\n4. Распакуйте архив в путь без кириллицы и специальных символов.\n\n5. Запустите подходящий файл.\n    * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.\n    * Чтобы включить автозапуск, выберите в **`service.bat`** пункт `Install Service`, затем нужную стратегию.\n\n## ℹ️Краткие описания файлов\n\n- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.\n\n  Такой запуск удобен для проверки вариантов. Результат зависит от множества условий, поэтому **перебирайте разные стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**.\n\n- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:\n  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc</ins>\n  - **`Remove Services`** — убрать стратегию и WinDivert из служб\n  - **`Check Status`** — посмотреть состояние обхода, автозапущенной стратегии и WinDivert\n  - **`Game Filter`** — включить или выключить обход для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  \n  **После смены режима стратегию нужно перезапустить.**  \n  В скобках отображается текущее состояние: включено или выключено.\n  - **`IPSet Filter`** — изменить режим обхода ресурсов из `ipset-all.txt`.  \n  Это полезно при проверке ресурса, который без zapret работает, а с ним — нет.  \n  В скобках показывается выбранный режим:\n    - `none` — IP-адреса не проверяются\n    - `loaded` — проверяется принадлежность IP списку\n    - `any` — под фильтр попадает любой IP  \n  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений\n  - **`Replace active fakes`** — заменить текущий fake на другой из каталога `bin`\n  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория\n  - **`Update Hosts File`** — обновить hosts <ins>**для исправления веб-версии Telegram и подключения к голосовому чату Discord**</ins>\n  - **`Check for Updates`** — вручную проверить наличие обновлений\n  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  \n  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного сбоя.\n  - **`Run Tests`** — запустить проверку стратегий:\n    - `Standard tests` — тестирование сайтов из `utils/targets.txt`\n    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon\n\n## ☑️Распространенные вопросы и проблемы\n\n### После запуска скрипта `general*` ничего не происходит\n\nПри запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  \nЕсли этого не произошло, обратитесь к [#522](https://github.com/Pyramidritake/zapret-discord-youtube/issues/522).\n\n### Ни одна стратегия не подходит\n\n- Откройте командную строку с правами администратора.\n- Выполните по очереди:\n\n    `netsh winsock reset`\n  \n    `netsh int ip reset all`\n  \n    `netsh winhttp reset proxy`\n  \n    `ipconfig /flushdns`\n\n- Перезагрузите компьютер.\n\n### Не работает телеграм (веб версия)\n\nВ **`service.bat`** выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  \n  - Скопируйте весь текст из открытого блокнота.\n  - Откройте от имени администратора файл `hosts` в появившейся папке.\n  - Вставьте скопированный текст в конец файла (либо замените ранее добавленный аналогичный блок).\n  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что hosts действительно сохранился.\n\n#### Работа не гарантирована. Если способ не помог, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Pyramidritake/tg-ws-proxy) или любым публичным прокси.\n\n### Обход не работает / перестал работать\n\n> [!IMPORTANT]\n> **Стратегии могут со временем переставать работать.**\n> Найденная стратегия способна какое-то время работать, а затем перестать из-за обнаружения.\n> В репозитории есть много стратегий. Если готовые варианты не помогают, создайте новую на основе одной из них, изменив параметры. Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).\n\n- Проверьте `service.bat` → `Run Diagnostics` и устраните найденные ошибки.\n- Убедитесь, что нужный адрес присутствует в списке доменов или IP.\n- Испытайте другие стратегии, включая **`ALT`** и **`FAKE`**.\n- Выполните полную переустановку по инструкции ниже.\n- См. [#765](https://github.com/Pyramidritake/zapret-discord-youtube/issues/765).\n\n### Как переустановить/обновить полностью?\n\n- Сохраните добавленные вами ресурсы и данные.\n- Перезапустите устройство.\n- Выполните `service.bat` → `Remove Services`.\n- Запустите `service.bat` → `Run Diagnostics`; если появятся ошибки, исправьте их и в конце выберите Y.\n- Удалите папку zapret.\n- Скачайте свежую версию [`zapret-discord-youtube-...`](https://github.com/Pyramidritake/zapret-discord-youtube/releases).\n- Откройте свойства архива правой кнопкой мыши. Если внизу есть пункт разблокировки, отметьте его, нажмите «Применить» и «ОК».\n- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.\n- Запускайте разные `general`-скрипты. Если ресурс не открывается, закройте программу через значок замка на панели задач и попробуйте другую стратегию.\n- После выбора рабочей стратегии включите её автозапуск через `service.bat` → `Install Service`.\n\n### Не работает игра/приложение с включённым запретом\n\n- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.\n\n### Античит ругается на WinDivert\n\n- Изучите инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide\n\n### Требуется цифровая подпись драйвера WinDivert (Windows 7)\n\n- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).\n\n### При удалении через [**`service.bat`**](./service.bat) WinDivert остаётся в службах\n\n1. В командной строке Windows (Win+R, `cmd`) найдите имя службы:\n\n```cmd\ndriverquery | find "Divert"\n```\n\n2. Остановите и удалите службу, подставив имя из предыдущего шага:\n\n```cmd\nsc stop название_из_первого_шага\n\nsc delete название_из_первого_шага\n```\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube\n\n- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).\n- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.\n- Если прежняя стратегия перестала помогать, проверьте остальные.\n- См. [#251](https://github.com/Pyramidritake/zapret-discord-youtube/discussions/251).\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord\n\n- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.\n- Сначала желательно выяснить, на какой стратегии открывается YouTube, и запустить именно её.\n- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.\n- Проверьте, помогла ли очистка в приложении Discord.\n- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею.\n- Если не работает и браузер, повторно испытайте все стратегии: YouTube и Discord могут работать на разных вариантах.\n- См. [#252](https://github.com/Pyramidritake/zapret-discord-youtube/discussions/252).\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram\n\n- Попробуйте [tg-ws-proxy](https://github.com/Pyramidritake/tg-ws-proxy).\n- Также можно использовать бесплатные MTProto-прокси из интернета.\n\n### Не работают игры\n\nИгр много, поэтому проверить и исправить каждую невозможно.\n\nПопробуйте следующий универсальный порядок:\n- в `service.bat` обновите ipset и включите `Game Filter`;\n- если это не сработало, дополнительно включите `ipset any`.\n\nУчтите: `ipset any` может нарушить открытие множества сайтов. Не оставляйте этот режим включённым постоянно. Лучше определить все IP игры и добавить их в `ipset-all.txt`.\n\nЕсли результата нет, создайте обсуждение в разделе [Discussions](https://github.com/Pyramidritake/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.\n\n### Не нашли своей проблемы\n\n- Оформите её [здесь](https://github.com/Pyramidritake/zapret-discord-youtube/issues).\n\n## 🗒️Добавление адресов прочих ресурсов\n\nДополнительные адреса для обхода добавляются в следующие файлы:\n- **`list-general-user.txt`** — домены; поддомены учитываются автоматически\n- **`list-exclude-user.txt`** — домены-исключения, например когда сеть уже есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно\n- **`ipset-all.txt`** — IP-адреса и подсети\n- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить\n  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.\n\n## ⭐Поддержка проекта\n\nПоддержать проект можно, поставив :star: этому репозиторию в правом верхнем углу страницы.\n\nМатериальная поддержка оригинального разработчика zapret доступна [здесь](https://github.com/bol-van/zapret?tab=readme-ov-file#%D0%BF%D0%BE%D0%B4%D0%B4%D0%B5%D1%80%D0%B6%D0%B0%D1%82%D1%8C-%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%87%D0%B8%D0%BA%D0%B0).\n\n## ⚖️Лицензирование\n\nПроект распространяется по лицензии [MIT](https://github.com/Pyramidritake/zapret-discord-youtube/blob/main/LICENSE.txt).\n\n## 🩷Благодарность участникам проекта\n\n[![Contributors](https://contrib.rocks/image?repo=Pyramidritake/zapret-discord-youtube)](https://github.com/Pyramidritake/zapret-discord-youtube/graphs/contributors)\n\n💖 Отдельная благодарность автору [zapret](https://github.com/bol-van/zapret) — [bol-van](https://github.com/bol-van)
